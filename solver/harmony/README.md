# solver/harmony: pilot scripts from the cross-field comparison of 2026-11-07

Six agents compared this project with neighbouring fields where a self-similar parameter is selected (notes/HARMONY.md,
notes/DINF_ANALYTIC.md §5a). These are their pilot scripts, one folder per field: brownian, dss_explosions, implosion,
larson_penston, magnetism, stokes. Their outputs and logs are in the raw-data repository's `harmony-mac/<field>/`.

They are exploratory and unreviewed. Some read files of this repository by absolute path and write to a scratch folder
of the Mac that ran them, so paths need adjusting before a rerun. Every value they produced is numerical evidence (two
precisions or settings agreeing), not an enclosure. Each folder's planted controls and mutations are named in
notes/HARMONY.md.
